## 📌 Resumen del Proyecto

**'Unidad D:\sentimientos'** es el proyecto de Trabajo Fin de Máster (TFM) del director de arte y productor bajo el alias **Johnny Lemonic**, publicado bajo el sello independiente **Estudios Ventorrillo**.

El proyecto fusiona la estética nostálgica del sistema operativo **Windows 95** con un proceso de creación contemporáneo: un diálogo entre la emoción humana y la generación musical asistida por Inteligencia Artificial (Suno AI). La aplicación web actúa como reproductor de música, portafolio 360 y ensayo visual interactivo que critica la cultura de las redes sociales mientras celebra la validez de las ideas conceptuales en la música digital.

---

## 🗂️ Estructura del Sistema Operativo Web

La aplicación simula un entorno de escritorio completo de los 90 con las siguientes funcionalidades interactivas:

- **💿 Reproductores de Audio (`.wav`):** Ventanas animadas con reproductor de audio e integración con videoclips oficiales de YouTube.
- **📝 Archivos de Texto (`.txt`):** Cuadros de texto estilo Bloc de Notas con las letras completas de los temas y enlaces incrustados a referentes culturales.
- **⚙️ Archivos de Datos (`.dat`):** Registro documental de los *prompts* de Suno AI utilizados para generar la instrumentación y arreglos de cada tema, con botón de copia rápida en un clic.
- **🖥️ Salvapantallas Dinámico & Reloj:** Salvapantallas estilo DVD rebotante con cambio de color aleatorio y activador manual desde el reloj del sistema.
- **📱 Responsive & Touch Ready:** Adaptación de interacción para móviles (toque único) y escritorio (doble clic y arrastre de ventanas).

## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML5, CSS3 nativo (Windows 95 UI), JavaScript (ES6+), Bootstrap 5.
- **Manipulación DOM & UX:** Manejo sintético de audio (Web Audio API / HTML5 Audio), Canvas animación de salvapantallas, ventanas arrastrables y redimensionables.
- **Producción Musical:** Generación de prompts y dirección creativa con **Suno AI**.
